Bounty Board v1.1

Post a bounty for a GitHub issue. Anyone can claim it with a pull request link. GenLayer validators read the live GitHub pages and must agree that the pull request is merged and really fixes the issue. Every claim is kept in the bounty's history, and a bounty stops accepting claims after 3 failed ones.
